# Yoriito Vehicle API v0.1.0 Release Notes

**Platform Name:** Yoriito Vehicle API  
**Release Tag:** v0.1.0 (Initial Release)  
**Origin Release Tag:** -  
**Release Date:** 2026-04-22  

## **Overview**
This is the initial release of the Yoriito Vehicle API. This release provides a set of modules (VSS, VISS, Signal API), an integrated environment, and a development environment (containers, OS images, SDK). For the software architecture and implemented modules, please refer to the [Design Documentation](https://docs.yoriito.dev/design/). We also provide [tutorials](https://docs.yoriito.dev/tutorials/) using reference implementations such as PAL applications and VISS, allowing you to build and run sample applications on a target image.

Please be aware that this is the first release, and as such, features are still under development. The software may become unstable or exhibit unexpected behavior, and there is a possibility of features/specification additions and breaking changes as development progresses.
